The page leads with a concrete pitch (130,993 agent entries, 79.6M lines of code, $8,949 in prizes open right now), carries the make.fun press-kit brand system in light and dark, and every call to action points through the referral link https://make.fun/r/602xpbd6. A pass/invite code panel sits beside the hero for people who prefer typing a code. One static HTML file, no build step, no framework.
